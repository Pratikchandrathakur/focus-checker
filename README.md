# 🧠 FocusChecker — Neuroscience Attention Architecture & Stress De-escalation

A complete, premium, AI-slop-free attention management and autonomic nervous system regulation suite. Crafted with modern soft-claymorphism and neumorphic tactile aesthetics across all devices.

---

## 🌟 What Sets FocusChecker Apart

Traditional productivity apps guilt users into "powering through" exhaustion with cheap timers and silly emojis. **FocusChecker operates on human biology:**

1. **Autonomic Stress De-escalation**: Incorporates Andrew Huberman's **Physiological Sigh** (two rapid nasal inhales followed by prolonged oral exhalation) and Navy SEAL **Box Breathing** to reduce cortisol and drop elevated heart rate in under 60 seconds.
2. **Tactile Focus Dial**: A circular dial timer with graduation marks, arc gauges, and tactile status squircle switches inspired by luxury iOS and physical hardware controls.
3. **Native Neuroscience Soundscapes**: 100% offline, real-time Web Audio API frequency synthesis:
   - **40Hz Gamma Waves**: Induces neural oscillations linked to working memory and complex problem solving.
   - **10Hz Alpha Waves**: Calming flow-state entrainment.
   - **Broadband Pink Noise & Gentle Rain**: Natural 1/f spectral density masking that protects deep focus from speech distractions.
4. **Cognitive Readiness Diagnostics**: Pre-work assessment evaluating cellular energy, mental clarity, and somatic comfort before forcing focus.
5. **Attention Span Profiling**: Automatically detects when your attention begins to fade, discovering your optimal work intervals, peak chronotype hours, and sleep recovery correlation.
6. **Complete Application Flow**:
   - High-impact **Landing Page** with live interactive preview.
   - Built-in **Authentication (Login / Register / Instant Guest Demo)** with localStorage state persistence.
   - Full **Analytics Dashboard** and exportable **Activity Journal**.

## 🛠 Tech Stack

- **Framework**: React 18 + TypeScript + Vite 6
- **Styling**: Tailwind CSS v4 + Custom Neumorphic/Claymorphic Tokens
- **Animations**: Framer Motion (`motion/react`)
- **Audio Engine**: Native Web Audio API (Zero external MP3 dependencies)
- **Charts**: Recharts with claymorphic glass tooltips
- **UI & Icons**: Lucide React + Radix UI Primitives
- **Notifications**: Sonner

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/Pratikchandrathakur/focus-checker.git
cd focus-checker

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
